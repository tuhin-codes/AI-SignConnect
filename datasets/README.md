# SignConnect Datasets Directory

This directory manages local dataset assets, provenance records, and inventories for SignConnect's research baseline experiments.

## Policies and Boundaries

1. **Research-Only Baseline:** Datasets stored here are acquired exclusively for research benchmarking, baseline development, and preprocessing evaluation under documented academic terms.
2. **Commercial Status:** Commercial production training: **NOT APPROVED**. Acquisition of any research baseline does not authorize or grant commercial rights.
3. **Git Protection:** Raw dataset archives, video files, frames, and binaries are strictly excluded from source control via `.gitignore`. Only documentation files (`README.md`, `MANIFEST.md`) are tracked in the repository.
4. **Separation of Assets:** Research datasets and derived artifacts must remain legally segregated from commercial production assets.

## Managed Datasets

- `isl-csltr/`: Indian Sign Language Dataset for Continuous Sign Language Translation and Recognition (Mendeley Data `kcmpdxky7p.1`, CC BY 4.0).
